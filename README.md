# Learn Marketing with Phoebe

Six 45-minute sessions on marketing fundamentals as decisions, in the order that makes each one
cheaper: who it is for (segments, the beachhead, the ICP), the promise against the real alternative
(April Dunford's positioning), where customers already are (the Bullseye from Traction), a funnel
bench, what a customer is worth (CAC, payback, LTV), and the plan on one page.

- Running product: Cadence, a fictional AI note-taker (constructed numbers, labelled on every page).
- Real data: the public Marketing Funnel by Olist (Kaggle, CC BY-NC-SA 4.0), all 8,000 leads and
  842 closed deals, shipped in `assets/funnel-sample.js` and computed in the browser by
  `assets/funnel-live.js` (session 4).
- No AI tooling and no code required for learners.

Static site, no build step. Open `index.html`, or serve the folder with `python3 -m http.server`.

By Phoebe Fu.
